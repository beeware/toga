The Cocoa, WinForms and Textual backends now use platformdirs to determine the base location of app-specific paths. Path locations are unchanged on Windows and Linux; on macOS, `app.paths.config` has moved from `~/Library/Preferences/<app id>` to `~/Library/Application Support/<app id>/Config`, and `app.paths.data` has moved from `~/Library/Application Support/<app id>` to a `Data` subfolder of that location, so that app paths cannot collide. Toga does not move any existing files; an app that needs to preserve files stored at an old location can migrate them at startup with a snippet like:

```python
import shutil
from pathlib import Path

# Example: the old macOS config location
old_config = Path.home() / f"Library/Preferences/{app.app_id}"
if old_config.exists():
    shutil.copytree(old_config, app.paths.config, dirs_exist_ok=True)
    shutil.rmtree(old_config)
```
